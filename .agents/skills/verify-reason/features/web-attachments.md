# Reason Web: attachments open in a viewer over the thread

Branch feat/web-attachments (2026-10-31). No flag. Omari: tapping a photo took the whole tab to /web/media/m/1611/0 (black page, picture small top-left, no way back).

- `src/pages/webviewer.js` (`VIEWER_CSS`, `VIEWER_JS`, `viewOf`, `viewSrc`), loaded on the thread and on a History day. A click on `.msg .photo` or `.msg a.fchip[data-view]` opens a `role="dialog" aria-modal` viewer; ⌘/Ctrl/middle click still opens the file's own address. Photos: centred in the paper frame, eyebrow `PHOTO · YOU · 5:23 PM`, the message's words in serif underneath, `2 OF 5` through every photo in the thread (←/→, the round arrows, a swipe), Download (the original), backdrop opaque paper from the first frame (only the content fades in); close by ×, Esc, a tap beside it, a swipe down, or the browser's Back (one pushState). A tap puts focus on the dialog (no ring), Enter puts it on ×; Tab is trapped, the page behind is `inert`, focus goes back to the photo. PDF: framed (`frame-src 'self'` now in SECURITY_HEADERS) + OPEN in a new tab + Download. Video / audio: native controls. Text (.txt/.md/.csv): fetched into a `<pre>`. Anything else, or a photo/video that fails: a file card (name, `DOCX · 12 KB`, Download it →). Reduced motion: no fade/scale.
- Thread thumbnails: a pulse while loading, `PHOTO` on error, frame width set from the picture's shape (height fixed, so nothing jumps). A picture Reason sent as a file (outbox file, e.g. a screenshot) is now a photo that opens (was a grey PHOTO box).
- `src/webmedia.js`: `?as=jpeg` (from `src/http.js`) turns a HEIC into a JPEG (heif-convert on Hetzner, sips on a Mac) after the same owner check; keyed by file (`fileKey`), shared while running, one at a time, cache 12 / 32 MB; can't convert → 404 → file card. The plain address is unchanged (original HEIC, same headers). CDN videos are served as video (were sent to the audio converter as audio/mp4).

Drive: `bin/web-attachments-drive.mjs [--shots=DIR] [--before]` — 7 HTTP steps (owner 200, others 404, HEIC ?as=jpeg) then WebKit iPhone, Chrome desktop and Chrome phone, light + night: 136 ok. Tests: `test/web-attachment-viewer.test.js` (9; 8 fail on main 97f4af9, the 9th was added with the review fix).
